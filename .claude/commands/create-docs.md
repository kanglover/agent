回顾本次对话，将核心知识点整理并保存为 Markdown 文档。

## 执行步骤

**第一步：提取核心内容**
从对话中找出值得长期保留的知识，包括：
- 概念解释（是什么）
- 解决的问题（为什么）
- 使用方法（怎么做）
- 对比分析（和其他东西的区别）
- 适用场景（什么时候用）

**第二步：确定文件名**
按照格式 `主题-关键词.md` 命名，例如：
- `prompt-基础写法.md`
- `openspec-规格驱动开发.md`
- `claude-code-上手指南.md`

**第三步：生成文档内容**
文档结构如下：
```
# 标题

> 沉淀时间：[今天日期]
> 来源/链接（如有）

## 一句话总结

## 核心是什么？

## 解决什么问题？

## 怎么用？（关键步骤或命令）

## 和相关概念的区别（如有对比）

## 适用场景

## 不适合的场景（可选）

---
*相关概念：[关键词标签]*
```

**第四步：写入文件**
将文档保存到项目根目录，路径为 `notes/notes/文件名.md`

**第五步：告知结果**
完成后告诉用户：
- 📄 保存了哪个文件
- 📌 记录了哪些核心知识点（3-5 条简要列出）

## 注意事项
- 语言用中文，保持简洁易读
- 术语必须有解释，不能让文档"看不懂"
- 如果本次对话涉及多个独立主题，分别创建多个文档
